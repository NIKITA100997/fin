# Приём уведомлений банков: настройка

## 1. База
Supabase → SQL Editor → выполнить `008_push_ingest.sql`.

Проверка, что номера карт встали на свои счета:
```sql
select bank, name, kind, last4, card_aliases, push_number from accounts order by bank;
```
Должно быть: Т-Банк кредитка — 0150 / {5546}; Т-Банк дебетовая — 0186 / {0979};
Сбер кредитка — 9728 / {3327}, push_number = spend_limit; Сбер дебетовая — {5333,1043}.
Если дебетовой Сбера нет в списке — добавьте её в приложении (Деньги → Новый счёт, банк «Сбер»,
другие номера: 5333, 1043).

## 2. Функция приёма
1. Supabase → Edge Functions → Deploy a new function → Via Editor.
2. Имя функции: `ingest`. Вставить содержимое `ingest-function.ts` целиком → Deploy.
3. В настройках функции выключить проверку JWT (Verify JWT / Enforce JWT verification):
   MacroDroid её не отправляет, вместо неё используется ваш ключ.

## 3. Приложение
1. Заменить в репозитории `app.js`, `styles.css`, `sw.js`.
2. Открыть приложение → Обзор → Настройки → «Создать ключ». Там же видны адрес и ключ.
3. Проверить «Мои имена»: Никита Б., Никита Сергеевич Б.

## 4. MacroDroid
1. Установить MacroDroid, выдать доступ к уведомлениям, отключить для него оптимизацию батареи.
2. Новый макрос.
   - **Триггер:** Уведомление → Уведомление получено. Приложения: СберБанк, Т-Банк, Ozon Банк,
     Пэй (Яндекс), Mir Pay. Текст: любой.
   - **Действие:** HTTP-запрос.
     - Метод: POST
     - URL: адрес из настроек приложения (`https://…supabase.co/functions/v1/ingest`)
     - Параметры запроса (Query parameters):
       - `token` = ваш ключ
       - `app` = магический текст «Имя приложения уведомления»
       - `title` = магический текст «Заголовок уведомления»
       - `text` = магический текст «Текст уведомления»
     Магический текст выбирается кнопкой «…» рядом с полем.
3. Сохранить и включить макрос.

## 5. Проверка
Сделайте перевод 10 ₽ между своими картами. Через несколько секунд в приложении на вкладке
«Деньги» должны появиться операции с пометкой «из уведомления», склеенные в один перевод.
Всё, что не распознано, — в блоке «Не распознано» сверху вкладки «Деньги».
Сырые уведомления видны в Supabase → Table Editor → raw_notifications (колонки status и reason).
